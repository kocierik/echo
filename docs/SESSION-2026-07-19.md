# Echo — Session Summary (2026-07-19)

## Decisioni MVP prese
- VAD software energy-based (sempre in ascolto)
- Wi-Fi diretto + buffer PSRAM quando offline
- Audio ADPCM (4:1 compression)
- HTTP POST chunked ogni 5-10s
- Whisper OpenAI API (italiano)
- Store-then-analyze (salvataggio immediato + analisi LLM asincrona)
- Entità strutturate (Person, Task, Idea, Event, Note) + vector search pgvector
- Chunking 500 token / 50 overlap per RAG
- Nessuna relazione esplicita tra entità (co-occorrenza implicita)
- Timeout silenzio + raggruppamento LLM per conversazioni
- GPT-4o-mini per analisi, GPT-4o per RAG
- OpenAI text-embedding-3-small (1536 dim)
- Single-user con API key + user_id nei dati
- Docker locale + Cloudflare Tunnel
- Arduino framework
- HTML/CSS/JS vanilla frontend
- LED + mute button hardware
- Audio retention 30 giorni
- No OTA nel MVP

## Implementato
- Backend FastAPI completo (routers: segments, query, conversations, entities)
- Background worker (STT → entity extraction → chunking → embeddings → titolo/riassunto)
- Modelli SQLAlchemy (Segment, Transcription, Conversation, Chunk, Entity, ApiKey)
- Servizi astratti + implementazione OpenAI (STT, LLM, Embedding)
- ADPCM decoder (backend) + encoder (firmware)
- Entity deduplication (fuzzy match + LLM confirmation)
- RAG migliorato con entità nel contesto
- Firmware ESP32-S3 completo (VAD, ADPCM, HTTP POST, PSRAM buffer, NTP, LED, mute)
- Web UI con chat + sidebar conversazioni + dettaglio entità
- Docker Compose (full + infra-only)
- Health check completo + stats endpoint
- Retention job automatico
- Unit test ADPCM decoder (7/7 pass)
- Documentazione: CONTEXT.md, 5 ADR, README, ROADMAP, DEVELOPMENT guide

- Workaround: docker-compose-infra.yml (solo DB+Redis in container) + backend locale
